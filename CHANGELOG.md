# Changelog

All notable changes to IHR BioAtlas are documented here.
Format: `[version] — date — description`

---

## [v3] — 2025-05 — Year 1 Release

### Data
- 809 specimen records from Year 1 sequencing runs (April–November 2025)
- 5 states: Himachal Pradesh, West Bengal, Arunachal Pradesh, Meghalaya, Nagaland
- 15 orders, 110 families, 237 genera, 208 species
- 451 BINs assigned via BOLD
- 689 specimens matched to PDF specimen photographs

### App
- Full standalone single-file HTML deployment
- Interactive Leaflet.js map: Dots / Heatmap / Cluster modes
- Analytics panel: ORDER_STATS bar chart, species richness donut chart
- ML Prediction panel: Random Forest genus-level occurrence probability
- Specimen Data table with full-text search and filter
- bioatlas_updater.py: GUI + CLI updater script for data refresh and metadata edits
